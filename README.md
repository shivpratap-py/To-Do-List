# 📝 To-Do List App

A modern and responsive To-Do List application built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Priority levels (Low, Medium, High)
- Filter tasks:
  - All
  - Active
  - Done
- Local Storage support (tasks persist after page refresh)
- Dark / Light theme toggle
- Responsive design for desktop, tablet, and mobile devices
- Clean and modern UI

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/todo-list.git
```

Navigate to the project folder:

```bash
cd todo-list
```

Open `index.html` in your browser.

## 💾 Data Persistence

Tasks are stored using the browser's Local Storage.

This means:

- Tasks remain after refreshing the page
- Tasks remain after closing and reopening the browser
- No backend or database is required
